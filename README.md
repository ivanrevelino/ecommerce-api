# E-commerce API

A RESTful e-commerce API built with Java and Spring Boot, designed to manage users, products, categories, authentication, and the core operations of an online store.

The API implements JWT-based authentication and role-based authorization, allowing administrators to manage products and categories while authenticated users can interact with the store.

### Main Features

* User registration and authentication
* JWT-based authentication
* Role-based authorization (`ADMIN` / `USER`)
* Product CRUD
* Category CRUD
* PostgreSQL database
* JPA/Hibernate for data persistence
* RESTful API architecture

The project is being developed with a focus on clean architecture, security, scalability, and real-world backend development practices.
